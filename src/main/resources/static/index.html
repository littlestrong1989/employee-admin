Employee Admin · 企业管理后台

Spring Boot 3 + JWT 鉴权 + 员工 CRUD + 分页检索 + Swagger 文档

Swagger UI H2 控制台 OpenAPI JSON

项目亮点

🔐 无状态 JWT 鉴权

登录签发 JWT，过滤器校验；未认证 401、无权限 403，语义清晰可区分。

🧩 员工 CRUD

新增 / 修改 / 删除 / 详情，删除操作通过 @PreAuthorize 限定 ROLE_ADMIN。

🔎 组合检索 + 分页

关键字、部门、在职状态任意组合，支持排序，返回统一分页结构。

✅ 参数校验

Jakarta Bean Validation + 全局异常处理，错误响应不泄露堆栈。

📘 Swagger 文档

springdoc-openapi 自动生成在线文档，可直接调试。

🗄️ 双 Profile

demo 用 H2 内存库免配置启动；mysql 切换生产库。

技术栈

Java 17Spring Boot 3.3.4 Spring Security 6JWT · jjwt 0.12.6 Spring Data JPAHibernate 6 H2 / MySQL 8springdoc-openapi LombokBean Validation

快速开始

# 克隆后直接运行（demo profile，H2 内存库，无需 MySQL）
mvn spring-boot:run

# 打开本页
open http://localhost:8080/
# Swagger UI : http://localhost:8080/swagger-ui.html
# H2 控制台  : http://localhost:8080/h2-console

# 演示账号
admin / admin123     (ROLE_ADMIN，可删除)

# 换 MySQL 跑
export DB_HOST=127.0.0.1 DB_NAME=employee_admin DB_USER=root DB_PASSWORD=你的密码
mvn spring-boot:run -Dspring-boot.run.profiles=mysql

命令行调用示例

# 1) 登录拿 token
curl -s -X POST http://localhost:8080/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"admin123"}'

# 2) 带 token 检索员工
curl -s "http://localhost:8080/api/employees?page=1&size=5&keyword=张" \
  -H "Authorization: Bearer <token>"

「在线体验」标签页可以直接在浏览器里调这些接口，不用敲 curl。
